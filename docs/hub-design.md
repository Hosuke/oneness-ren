# oneness.ren 主站設計 · 仁為門，行履為路

> 2026-09-26 草案。雙軌：cc 與 Codex 各出一稿，本文為合稿。標「待裁」者由主人定。

## 〇、一句話

進門仍只有「仁」。路不在門口，在卷末、在字裡；想找的人一定找得到，不找的人只看見紙與字。

原則：
- 主人**持續書寫**之事（日誌、法訊、遍路）入主站路徑；**獨立作品**（斯文、太虛、曼荼羅）保留自己的域名與倉庫。
- 尚無內容者不掛空門。新主題先添路徑，待其有獨立讀法與維護週期，才考慮分站。
- 各頁 canonical 指自身，不指回仁。

## 二、隱門：怎麼「溫柔地藏」

三個方案比較後，**主門取「卷末見路」，副門取「門字」**：

1. **卷末見路（主）**：收尾沉石之景、印章之下，常駐一行小字「行履 · the way on」→ `/walk/`，旁附一句「紙外，尚有行路。」隨捲動自然入眼；無手勢、無 JS 亦可達；讀屏與鍵盤天然可用。首屏三行不動。
2. **門字（副，給熟客的驚喜）**：在首屏「仁」近旁停駐約 2.5 秒（觸屏長按，鍵盤聚焦「仁」後 Enter），諸語聚攏之後，「仁」周圍浮起六個朱色細線的單字，如水底石上的刻痕：
   `文` 斯文 · `經` 太虛 · `壇` 曼荼羅 · `路` 遍路 · `記` 日誌 · `訊` 法訊
   離開則緩緩沉回。尚未開張的門（記、訊）不顯。
3. **浮字為門（不採為主）**：如「同行二人」卡末附「讀遍路」。有詩意，但混淆「出處」與「導航」，只在確有關聯時作卡內延伸閱讀。

無障礙與 SEO：隱只隱於視覺層；`/walk/` 為完整目錄，`sitemap.xml` + `robots.txt` 指明；不以 `aria-hidden` 或 `display:none` 封門；浮字動畫已有「靜 · still」開關。

## 三、內容模型（無構建之約下）

- 每篇為一個實體 `index.html`（沿一份短範本），正文不靠 `fetch`；JSON 只存索引。
- **待裁**：長年寫作若手寫 HTML 太累，可允許「作者端生成」——一支零依賴的 `tools/press.mjs` 把 Markdown 轉成靜態 HTML，**產物提交入庫、部署不編譯**。這在字面上是一個構建步驟，須主人明許，不以「不用 npm」偷換。建議：先手寫三篇真實日誌，試出負擔再定。
- **日誌**：私稿永不入公開倉庫（另置私庫或本機），僅 `public` 篇入庫；同行者姓名、照片、行蹤逐篇審視。隱藏網址與 `noindex` 不等於保密。
- **法訊**：每條必載寺院、地址、起訖、報名截止、**官方原址**、官方刊日、最後核對日、狀態。缺官方依據不刊；摘要自寫；改期/取消留修訂註記；過期自動移出「近期」，但原頁長留並標往期；來源失效標「待核」，不推定取消。
- **遍路**：以寺號（01–88）為穩定識別；里程、費用、交通、住宿皆附來源與核對日，親歷另標；地圖之外必有可讀的路線文字。88 寺基本表以四国八十八ヶ所霊場会官方頁為源。
- 各欄 `feed.xml`，總站一份；固定 GUID、絕對網址、只收公開內容。

## 四、視覺連續

- 共用紙 `#f4efe4`、墨 `#1a1814`、朱 `#b8472a`、夜 `#0e0d0b`；子頁正文約 18px、行高 1.9，不重播浮字，安靜落定。
- **仁印**：一份小 SVG + CSS 片段，各子站頁尾放一枚，標「歸仁」，點之回 `oneness.ren`；旁附「行履」直達 `/walk/`。各倉各存一份帶版本號的副本（不跨域熱連）。
- 斯文、太虛保留原有閱讀介面，曼荼羅保留其圖像空間——以印章與頁尾相認，不強求一式。

- 2026-09-27 已接域：`https://oneness.ren/`（GitHub Pages + Cloudflare DNS-only；舊址 hosuke.github.io/oneness-ren/ 自動轉址）。
